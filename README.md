# Student Management System

A beginner-friendly Python project that allows users to manage student records, calculate marks, percentages, and grades.

## Features

- Add student records.
- Enter marks for Python, Mathematics, and English.
- Calculate total marks and percentage.
- Automatically assign grades.
- View all student records.
- Search for students by name.
- Validate marks between 0 and 100.
- Handle invalid numeric inputs using try-except.
- Menu-driven program.

## Grading System

| Percentage | Grade |
|---|---|
| 80% and above | A |
| 70%–79% | B |
| 60%–69% | C |
| 50%–59% | D |
| Below 50% | Fail |

## Technologies Used

- Python
- Lists
- Dictionaries
- While loops
- Conditional statements
- Try-except exception handling

## How to Run

1. Download the Python file.
2. Open it using Python or a code editor.
3. Run the program.
4. Select an option from the menu.

## Purpose

This project was created to practice Python programming concepts through a practical student record management application.
